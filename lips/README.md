# LVS Improvement Proposals (LIPs)


LIPs are design documents for the **Living Value System (LVS)**.


They:


- provide a clear history of protocol decisions;
- document consensus changes and economic rules;
- act as a reference for implementers.


LIPs follow a simple format:


- `LIP-XXXX-title.md` – where `XXXX` is a zero-padded number.
- header with metadata (ID, title, author, status, type).
- sections: Motivation, Specification, Rationale, Security, References.


See `LIP-0001` for a template.
