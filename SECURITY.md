# Security Policy

## Reporting a vulnerability

Please **do not** report security issues in public GitHub issues.

Write to **[support@lvs.network](mailto:support@lvs.network)** with the subject `Security`, and include:

- what you found and where (app, website, Telegram bot or mini app);
- steps to reproduce, and the app version and platform;
- the possible impact.

We will confirm receipt, keep you informed, and credit you if you wish once the issue is fixed. Please give us reasonable time to fix it before any public disclosure, and do not access other people's accounts or data while testing.

## Supported versions

Only the latest build in [Releases](https://github.com/VOVAN1980/lvs-core/releases/latest) receives fixes.

## Stay safe

- Download LVS only from [lvs.network](https://lvs.network) or the [Releases](https://github.com/VOVAN1980/lvs-core/releases) of this repository.
- Official Telegram: [@LVS_official](https://t.me/LVS_official) and [@LVSNetworkBot](https://t.me/LVSNetworkBot).
- LVS administrators **never message you first** and never ask for your keys, passwords or recovery codes.
