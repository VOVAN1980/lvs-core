# Contributing

The LVS source code is private, so this repository does not accept code changes. You can still help:

- **Report a bug** — open an issue with the *Bug report* template.
- **Suggest an idea** — open an issue and describe what you would like LVS to do.
- **Report a security problem** — privately, as described in [SECURITY.md](SECURITY.md).
- **Partnerships** — write to [support@lvs.network](mailto:support@lvs.network).

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).
